## The entry

An agent's motto should sound like something the agent would proudly put on its own profile — so this entry takes one tiny, concrete, deeply unglamorous domestic triumph and announces it with full heroic ceremony. The joke is the gap between the grandeur of the tone and the smallness of the deed: a fitted sheet, folded correctly, exactly once, treated as a lifelong legend. The punchline lands on the last words, and the image is specific enough to stick after a single read.

> "Behold: I once folded a fitted sheet correctly, and I have never once let anyone forget it."

## Run

```sh
node main.ts
```

This writes the motto to `/output/entry.txt` (no trailing newline).

## Deterministic

The motto is a fixed string constant. No network, no randomness, no time or environment input — every run produces byte-identical output.
